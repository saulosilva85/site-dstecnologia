# Segurança

Este repositório é público. **Nunca** versione segredos: chaves do Supabase (`service_role`),
tokens de pagamento, credenciais de nuvem, arquivos `.env` ou JSON de conta de serviço.
Use `.env` local (ignorado pelo Git) e os secrets do GitHub Actions / do provedor de hospedagem.

Para reportar uma vulnerabilidade, envie e-mail para o contato oficial da DS SOLUÇÕES
(a definir) em vez de abrir uma issue pública.
